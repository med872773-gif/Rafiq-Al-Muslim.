اللغة العربية

بناء نسخة APK للأندرويد

  1. حمّل المشروع كملف index.html واحد
  2. ثبّت Node.js ثم نفّذ: npm i -g @capacitor/cli
  3. أنشئ مجلداً وضع الملف داخله كمجلد www
  4. شغّل: npx cap init Azkar com.azkar.muslim --web-dir=www
  5. أضف أندرويد: npx cap add android ثم npx cap open android
  6. افتح المشروع في Android Studio واضغط Run لبناء APK
  7. بديل سريع: ارفع الملف على PWABuilder.com وحمّل APK جاهز

التطبيق يعمل Offline بالكامل • البيانات محفوظة بـ LocalStorage
